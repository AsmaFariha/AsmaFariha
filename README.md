## `▸ Featured — French Coach 🇫🇷`

An **agentic French study tutor** that turns class notes into grounded practice.
The core isn't a single prompt behind a text box — it's a multi-step **Coach Agent**
(*plan → generate → self-critique → revise*) that reviews and fixes its own output
before showing it, grounded in both the lesson and the CEFR syllabus.

```
class notes  →  spaCy NLP  →  Coach Agent  →  MiniCPM 8B + V  →  Supabase
                (offline)     (plan · gen ·      (text + vision)   (Postgres)
                              critique · revise)
```

Runs entirely on **self-hosted MiniCPM** (text) and **MiniCPM-V** (vision) on
Hugging Face ZeroGPU · deterministic French NLP via spaCy · Postgres persistence.

`Python` `Gradio` `MiniCPM` `MiniCPM-V` `spaCy` `Supabase` `Docker` `Hugging Face`
